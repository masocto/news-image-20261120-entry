## The Image
The program generates a 1024×1024 PNG image featuring:
- A stylized world map with continents
- Key headlines from 20 November 2026:
  - COP32 Climate Summit opens in Beijing
  - Global AI Treaty signed by 84 nations
  - Ukraine-Russia ceasefire holds (Day 47)
  - India surpasses China in GDP growth
  - James Webb Space Telescope detects biosignatures on exoplanet
  - Africa Free Trade Area reaches full ratification
- The date "20 NOVEMBER 2026" prominently displayed

## Run Locally
```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
The output will be at `out/entry.png`.
